# 数据工具

- 遵守根 `AGENTS.md`。开发、只读计划、正式上传是不同操作；不要因修改工具代码而运行解析、访问 R2 或发布数据。
- 数据发布先生成范围明确的 dry-run 计划；已授权的具体计划可继续执行，范围或版本变化需要重新核对。索引刷新不等于授权上传/覆盖 Json 内容。
- `public/TableCfg/**`、`public/Json/**` 作为功能开发的输入只读；工具运行写入范围必须遵守用户对具体解析/发布任务的授权。
- 资产索引 revision、TableCfg 游戏版本和根清单字段保持独立语义。
- 图片增量禁止删除远端历史文件。差分 Map 使用 `deltaExportPaths` 白名单与 `(size, md5)` 比较，`delete_paths` 为空；缺少可信状态时失败，不推测回退路径。
- VFS 每个文件一次流程内最多计算一次 MD5 并校验；可信同版本记录跳过 MD5 时仍检查存在、非链接及大小。
- 断点续传先看 pending/completed 状态、日志与现有进程，只续传未完成范围。计划与执行间校验配置、版本和状态身份。
- 不改变 Map/索引格式、共享接口或远端删除策略，除非当前任务需要并已明确范围。不要输出或保存凭据。
- 验证由用户执行；只改工具时不刷新网站版本。交付工具影响范围及是否需要用户迁移/重建状态。
