# AKEData版本更新日志

### v1.2.18

#### 地区建设

- 新增“地区建设”模块，汇总各地区等级所需成长值、矿物产量、等级说明与奖励，以及据点管理和地区设施升级信息。
- 矿点明细按地区展示矿物数量、纯度和计算后的每分钟产量，并提供新增矿点标记与“在 OEM 查看”定位链接。
- 据点管理展示各据点等级、升级所需发展值、特性和逐项物资兑换；地区设施展示各等级升级调度券消耗、说明和奖励。
- 地区等级产量、矿点明细、据点管理和地区设施等级均可独立展开，默认保持收起。

#### 角色与特殊语音

- 角色语音记录新增编队切换、切换干员等特殊情境语音，整合 `ResponsiveDialog` 与 `AIBarkText` 文本，过滤与常规档案语音重复的记录。
- 没有对照文本的特殊语音统一显示“该语音暂无对照文本”。
- 角色起始页恢复后勤技能房间筛选；筛选激活时显示两个后勤技能图标和悬停说明，未筛选时显示带深色背景的角色主、副能力图标。

#### 寻访记录

- 活动模块新增角色寻访与武库寻访历史表格，展示寻访池开放起止时间和持续天数。
- 新增覆盖最早至最新寻访池的时间轴，按周分度，每周宽度为 20 像素。

#### 武器与装备

- 武器支持按能力值、属性和系列技能三类词条筛选，并依据 `GemTable` 修正词条映射；三星武器不参与词条筛选。
- 装备支持按三个词条维度筛选金色品质单件装备；筛选结果以单件卡片展示，并修正属性类型与名称映射。
- 新增“精锻推荐”，按同部位、同副属性的初始值推荐更高成功率的强化素材；推荐弹窗会区分较好适配与自身兜底结果。
- 装备筛选区支持折叠，并优化筛选间距和精锻推荐弹窗尺寸。

#### 侧栏与界面

- 补齐标准目录模块的侧栏拖拽注册，修复资产、地区建设等模块无法调整左栏宽度的问题。

### v1.2.17

#### 杂项模块

- 新增“配方流程查看器”，支持按物品名称或 ID 搜索，并查看选中物品的上游生产配方与下游即时用途。
- 配方流程整合制造机、手工、枢纽、装备、飞船舱室、燃料、电力、采集和流体等生产关系，并支持展开替代配方与重复配方。
- 流程图支持缩放、拖拽、全屏查看和 PNG 导出，点击物品可以继续追踪新的配方链。

#### 富文本与技能弹窗

- RichTextStyleTable 现在按照网站主题选择颜色：亮色和护眼模式使用第一组，暗色模式使用第二组。
- 角色技能弹窗生成器固定使用第二组样式，保持游戏深色弹窗中的富文本颜色、图标和缩放比例一致。

#### 启动与路由

- 修复新用户首次加载接近完成时因 Service Worker 首次接管而自动刷新页面的问题。
- 刷新和启动恢复时保留 `plugin/id` 深链接，并兼容旧版 `v2_*` 模块链接。
- 修复模块清单加载失败被误显示为 404，以及 404 页面清除原始路由的问题。

#### 其他

- 图片水印中的站点域名更新为 `AKEData.wiki`。

### v1.2.16

#### 档案库

- 新增“地图文本”和“任务文本”分类，分别收录关卡环境调查文本、地图交互对话和 `PrtsReading` 中的任务文本；每段对话按独立条目展示，并使用首句作为条目名称。
- 档案库起始页和目录支持按地区、档案类型筛选，筛选栏可以折叠或展开；目录和卡片副标题统一显示“地区 · 内容类型”。
- 档案库左侧目录改为扁平条目布局，点击条目后返回起始页会保留进入前的搜索、筛选和滚动位置，不再强制刷新页面。
- 隐藏模式关闭时不显示档案组 ID、条目 ID、内容 ID、目录项 ID 和关卡脚本路径等游戏内标识。

#### 版本差异与文本解析

- 档案库 Latest 数据继续与上一个游戏大版本的最终 Hotfix 比较；地图文本使用 `DialogTextTable`，任务文本使用 `PrtsReading` 进行差异识别。
- 修正任务文本标题从空引用补全时被误标为“修改”的问题；仅本地化标题或副标题补全不再作为内容修改。
- 修正 `text_` 内容 ID 与对应 `radio_` 文本未关联的问题，补齐“关于远眺点α的侦察报告”等任务文本的正文和字幕显示。

### v1.2.15

#### 角色图标与技能弹窗

- 角色图标生成器新增 `1024 × 1024` 预设，并支持自定义宽高；锁定长宽比时会自动同步另一边的尺寸，非正方形画布会保持原构图比例并居中渲染。
- 技能带属性构图支持按技能类型和伤害属性渲染背景素材，并允许分别启用或关闭技能、背景底色、技能类型背景、属性颜色、角色图标、外环和装饰图层。
- 新增角色技能弹窗生成器，支持游戏富文本、链接图标、技能参数、分支技能、终结技消耗与冷却时间，以及角色天赋和属性节点的等级展示。
- 技能弹窗支持自主编辑原始文本和背景图片；编辑状态下的预览图与导出图会写入隐蔽定位水印，并新增图片水印解析器。
- 水印写入和读取改为中心优先，增强频域量化强度，并保留完整图片扫描兜底；解析器支持选择图片和粘贴图片。

#### 资产模块

- 资产版本现在同时解析游戏版本与 `@` 后的 Hotfix 编号，按完整的最高资产版本判断当前新增内容，不再忽略 Hotfix 差异。
- 为游戏 Sprite 目录增加本地化别名，资产目录、目录树、快捷跳转和文件夹卡片会显示更易识别的素材分类名称。
- 新增内容会在文件夹和文件层级显示“新增”标记，并在目录、搜索结果和文件列表中优先排列；选中的文件仍会保持在对应优先级内。
- 资产模块的“快速跳转”和“资产目录”支持独立折叠，桌面端和移动端均可使用；根目录和目录页的内容区分组也进行了统一整理。

### v1.2.14

#### 资产模块增强

- 资产文件现在会根据统一资产索引中的最高有效游戏版本显示“新增”标签；当前版本首次出现的新路径和覆盖更新的已有路径均会标记。
- 新增“仅看新增”筛选，支持桌面端和移动端同步切换，并同步过滤文件卡片、目录树和搜索结果。
- 根目录新增“游戏图标”和“游戏地图”快捷跳转，左侧桌面目录和移动端目录同时提供快速入口。
- 版本判断仅使用 `version` 中 `@` 前的游戏版本号；基线 `1.4.4` 不会被整批标记，Hotfix 不参与版本分组。

### v1.2.13

#### 统一资产索引与资产模块

- 新增带访问令牌的“资产”模块，可按目录浏览远端图片与 Json 资源，预览图片并下载文件。
- 图片和 Json 现在由远端 `asset-sync-index` 统一描述版本；它与 `version.json` 中负责 TableCfg 的游戏数据版本相互独立。
- 资产同步不再依赖 Json 目录中的 `manifest.json`，后续运行时也不生成本地或远端 manifest。

#### 数据加载架构

- 首页脚本和动态模块脚本改为并行预取、按原始顺序执行，减少串行网络瀑布。
- 新增有限并发数据加载器，支持请求去重、优先级调度、批量 Table 加载、共享取消等待和加载统计。
- 大型 JSON 解析移至 Worker；文本表改为本地化文本与中文回退按需查询，减少主线程解析和对象合并压力。
- IndexedDB 改为短等待后优先进入网络请求，并合并缓存读写事务；加载进度使用帧调度更新。
- Service Worker 改为后台启动，不再阻塞首页显示。

#### 稳定性修复

- 修正模块脚本并行预取后的执行等待，避免将未完成的 Promise 当作脚本文本执行。
- 修正资产索引版本与 TableCfg `sharedRevision` 的错误耦合，避免两套独立数据版本互相触发冲突。

### v1.2.12

#### 角色与技能

- 角色左侧目录新增武器类型图标，角色详情标签同步显示武器类型。

- 活动说明、奖励、物品、关卡和地下城等附属表改为打开对应活动详情后按需加载；活动起始页不再提前请求这些数据。
- 活动总览卡片图片改为靠右显示，同时保持素材原始比例与既有展示尺寸。

#### 侧边栏与资源版本

- 进一步降低主侧栏和各模块侧栏的最小宽度；有图标的条目在窄侧栏下仅显示图标，主侧栏不会再随缩窄而直接隐藏图标。
- `version.json` 新增亮色、暗色和护眼主题的独立 CSS 版本控制，未改动的主题资源可继续使用缓存。

### v1.2.4

#### 商店模块

- 新增商店模块（`v3_shop`），按商店组归类展示地区交易所、配额兑换、信用交易、付费商店和武库交易所等全部游戏商店。

- 商店模块接入跨版本数据差异查询：使用 Latest 时自动加载上一游戏版本的商店表数据，新增商店组和商品置顶并标记绿色"新增"角标。
- 若旧版缺失某表（如 `ShopGoodsTagCommonTable`、`GachaWeaponPoolContentTable`），数据层自动返回空对象保证比对正常进行，适用于所有模块。
- ID 字段在隐藏模式下被 CSS 规则统一隐藏。

### v1.2.3

#### 模块与信息显示

- 任务模块暂时隐藏，并标记为“开发中”；BuffData、SkillData 与 SpawnerConfig 调试模块现已停用。战争回响入口说明调整为“查看战争回响数据”。
- 未开启“显示隐藏模块”时，角色、装备、活动、Buff 等内部 ID 不再显示；“显示原始值”和计算公式功能改为常态提供，不再依赖隐藏模式。
- 属性修正会按来源合并为“出生加成”“buff加成”“副本加成”等摘要。敌人模块中的属性 Buff 也会参与实际计算；隐藏模式关闭时不显示 Buff ID 或无属性加成的 Buff。

#### 怪物与玩法模块

- 副本、危机合约和战争回响改为共用同一套怪物渲染逻辑，统一展示等级属性、出生 Buff 与修正结果，并统一使用新的元素抗性数据（94–99）；旧抗性系数（80–85）不再显示。
- 战争回响轮换支持展开与收起，并以外框颜色区分进行中、未开始和已结束状态。默认仅展开进行中的轮换，每个轮换默认仅展开最高难度的怪物配置。
- 同一关卡三个难度的特性描述与特性增益相同时，会在所有难度之前统一展示；只有内容不同时才分别显示。
- 修复危机合约 `v2cc-term-param` 参数渲染；活动配置默认收起，并隐藏任务解锁条件。

#### 活动与页面细节

- 活动起始页新增活动日历时间轴，显示活动开启、结束与当前状态。时间轴支持日期悬浮提示、视口外标题贴左显示，以及上下铺满并贴右对齐的活动图标；点击模块主页按钮返回时也会正确重新渲染。
- 修复角色和武器技能说明中的转义换行；装备制造消耗按钮左侧新增默认使用的装备元件图标。
- 导出长图功能结束测试状态并默认开启。所有模块导出时均移除左侧栏，并按当前模块或页面生成正确文件名。

#### 数据加载与公告

- TableCfg 的持久缓存现在只在 Hotfix 变化时更新；Json 与图片使用独立的共享数据修订号，不再因网站版本或 Hotfix 变化而重复加载。
- 网站公告现支持 Markdown 标题、列表、行内代码等语法。关于页面与 README 新增“终末地一图流”数据合作友链。

### v1.2.2

“显示原始值”与计算公式改为点击数值后打开常驻浮层，不再使用鼠标悬停提示。点击另一个数值会切换内容，点击网页空白处或按 Esc 关闭；浮层会随滚动和窗口尺寸变化重新定位，并适配移动端与键盘操作。数值本身保持原有显示样式。

修复部分模块父级点击事件导致真实鼠标点击无法打开浮层的问题，并修复角色 `chr_0032_lizhiyan` 技能原始值显示为 `[object Object]`。

### v1.2.1

修复在切换模块或 Service Worker 休眠重启后，部分游戏图片可能错误地从 `www.akedata.wiki` 请求的问题。图片路径现在会在写入页面时同步改写到 `data.akedata.wiki`，覆盖动态 HTML、图片属性、`srcset`、海报和内联背景图。

Service Worker 现在会从自身注册地址恢复数据域与共享数据修订号，并在应用初始化时完成配置；即使浏览器回收并重新启动 Worker，也不会丢失图片代理状态。网站图标也已改为直接从数据域加载。

新增 `LevelScriptData` 怪物数据解析，并接入普通副本、危机合约与战争回响的属性计算。现在可以读取脚本内直接定义的敌人、等级和出生 Buff，也可以识别按生成器施加的条件 Buff；即使关卡没有 SpawnerConfig，仍能正确计算怪物属性。危机合约词条 Buff 的预加载与切换后重算也已同步修复。

改进“显示原始值”功能：未发生业务计算改动的数值继续按原方式显示原始值；经过属性修正、Buff、危机词条或表达式计算的数值，则会显示原始值、代入参数、完整计算公式与最终结果。怪物属性公式现已覆盖副本、危机合约、战争回响和敌人模块，角色、武器、装备及物品说明中的计算表达式也会保留公式来源。

### v1.2.0

新增跨游戏版本的数据差异查询。使用 `Latest` 时，网站会自动与上一个游戏版本的最后一个 Hotfix 比较；新增数据始终置顶并显示标签，修改数据和详情 Diff 可通过全局设置中的“显示版本间数据改动（测试功能）”开关启用，默认关闭。

详情 Diff 只比较页面实际展示的信息，删除内容标红、新增内容标绿，隐藏字段不参与比较。活动不进行新增判定；装备按单件装备 ID 判断新增，并同步标记所属套组（包括独立装备）；奖章按具体奖章 ID 判断新增，并同步标记所属分类。新增状态仅通过标签区分，卡片外圈仍使用原有稀有度颜色。
