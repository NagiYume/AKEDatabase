# AKEGF 工具认证

工具认证面向提供抽卡记录迁移功能的应用。应用须同时支持导入和导出 v0.3 档案，并在应用内声明支持的版本，附上 [AKEGF 首页](https://www.akedata.wiki/?plugin=akegf&id=home)链接。文件的字段类型、条件必填项和分组合并规则见[标准化文档](/?plugin=akegf&id=standard)。

如果你的项目使用了 AKEGF 标准，欢迎通过 [Pull Request](https://github.com/NagiYume/AKEDatabase/pulls) 将你的项目添加到这里

## 导入后再导出的检查方法

1. 下载[多角色示例](/plugin/data/akegf/example.json)，导入应用，再从应用导出这些角色的记录。
2. 用本页表单检查导出的 JSON。校验通过表明这份文件符合 v0.3 的结构和唯一性规则；工具认证还需要对照导入前后的数据。
3. 按 `(region, server_id, uid)` 对照角色分组。示例中的国服角色应保留三条流水，国际服角色应保留一条。国服角色的干员抽取和武器申领具有相同的毫秒时间和流水号，但来源类别不同，导出后应仍有两条记录。
4. 逐条核对事件类型、卡池、获得物、星级、毫秒时间，以及来源已提供的流水号。示例中的赠送武器应保留为 `gift_weapon`，长流水号 `90071992547409931` 应按字符串原样保留。

## 格式校验工具

粘贴完整的 JSON 后点击「校验 JSON」，或选择本机文件直接校验。内容仅在当前浏览器中处理。

工具按 v0.3 Schema 检查字段、类型和取值，再检查重复角色分组和分组内重复流水号。例如，错误路径 `/endfield/0/list/1` 指向第一个角色的第二条流水。
