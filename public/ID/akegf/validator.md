# AKEGF · Sertifikasi alat

Sertifikasi mengharuskan aplikasi mendukung impor dan ekspor v1.1 / v1.2. Tampilkan versi yang didukung beserta tautan ke [AKEGF](https://www.akedata.wiki/?plugin=akegf&id=home).

Proyek yang mendukung AKEGF dapat mengirim [Pull Request](https://github.com/NagiYume/AKEDatabase/pulls) untuk ditambahkan ke [Proyek mitra](/?plugin=akegf&id=partners).

Impor [Contoh dengan beberapa karakter](/plugin/data/akegf/example.json), lalu ekspor kembali. Karakter server Tiongkok harus tetap memiliki tiga catatan dan karakter global satu. Bandingkan jenis, banner, hasil, kelangkaan, waktu milidetik, dan nomor urut. Pertahankan catatan operator dan senjata yang bernomor sama serta jenis gift_weapon untuk senjata hadiah.

## Pemeriksa format AKEGF

Tempel JSON atau pilih berkas lokal. Peramban memeriksa skema, grup ganda, dan nomor urut ganda dalam jenis yang sama. /endfield/0/list/1 menunjukkan catatan kedua karakter pertama.
