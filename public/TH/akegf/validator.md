# AKEGF · การรับรองเครื่องมือ

เครื่องมือที่ขอรับรองต้องนำเข้าและส่งออก v0.3 ได้ ระบุเวอร์ชันที่รองรับและใส่ลิงก์ [AKEGF](https://www.akedata.wiki/?plugin=akegf&id=home) ในแอป

โครงการที่ใช้ AKEGF สามารถส่ง [Pull Request](https://github.com/NagiYume/AKEDatabase/pulls) เพื่อขอเพิ่มรายชื่อในหน้า[โครงการพันธมิตร](/?plugin=akegf&id=partners)

นำเข้า[ตัวอย่างหลายตัวละคร](/plugin/data/akegf/example.json)แล้วส่งออกอีกครั้ง ตัวละครเซิร์ฟเวอร์จีนต้องเหลือสามรายการและเซิร์ฟเวอร์สากลหนึ่งรายการ เปรียบเทียบประเภท ตู้ ผลที่ได้รับ ความหายาก เวลามิลลิวินาที และเลขลำดับ เก็บทั้งรายการตัวละครและอาวุธที่มีเลขลำดับเดียวกัน รวมถึงประเภท gift_weapon ของอาวุธของขวัญ

## เครื่องมือตรวจสอบ AKEGF

วาง JSON หรือเลือกไฟล์ในเครื่อง เบราว์เซอร์จะตรวจ Schema กลุ่มตัวละครซ้ำ และเลขลำดับซ้ำในประเภทเดียวกัน /endfield/0/list/1 หมายถึงรายการที่สองของตัวละครแรก
