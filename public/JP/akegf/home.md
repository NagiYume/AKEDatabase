# AKEGF · ホーム

> ArKnights: Endfield Gachalog Format · v1.2

AKEGF は『アークナイツ：エンドフィールド』のスカウト・武器調達・贈呈の履歴を UTF-8 JSON で交換するための形式です。[UIGF](https://uigf.org/) を参考に、複数キャラクターやサーバーの履歴を一つのファイルにまとめ、ツールを乗り換えても履歴を引き継げるようにしました。

アプリ内に対応バージョンと [AKEGF](https://www.akedata.wiki/?plugin=akegf&id=home) へのリンクを表示してください。フィールドは[仕様書](/?plugin=akegf&id=standard)、入出力の確認方法は[AKEGF 形式チェッカー](/?plugin=akegf&id=validator)を参照してください。

[仕様書](/?plugin=akegf&id=standard) · [AKEGF 形式チェッカー](/?plugin=akegf&id=validator) · [参加プロジェクト](/?plugin=akegf&id=partners)
