# AKEGF · ツール認証

認証には v1.1 / v1.2 のインポートとエクスポートの両方が必要です。アプリ内に対応バージョンと [AKEGF](https://www.akedata.wiki/?plugin=akegf&id=home) へのリンクを記載してください。

AKEGF 対応プロジェクトは [Pull Request](https://github.com/NagiYume/AKEDatabase/pulls) で[参加プロジェクト](/?plugin=akegf&id=partners)への掲載を申請できます。

[複数キャラクターのサンプル](/plugin/data/akegf/example.json)を読み込んで再出力し、中国版の3件とグローバル版の1件が残ることを確認します。イベント種別、プール、結果、レア度、ミリ秒時刻、連番を照合してください。同じ番号のスカウトと武器調達を区別し、贈呈武器の gift_weapon を保持します。

## AKEGF 形式チェッカー

JSON を貼り付けるかローカルファイルを選択してください。ブラウザー内で形式、グループの重複、同一種別内の連番の重複を検査します。/endfield/0/list/1 は最初のキャラクターの2件目を指します。
