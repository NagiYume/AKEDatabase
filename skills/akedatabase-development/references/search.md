# 搜索索引维护

- 全站搜索的模块用表清单维护在 `plugin/js/search-index.js`，条目归属与路由规则维护在 `plugin/js/search-data.js`。新增模块、调整用表、关联字段、条目收录或路由时，同轮更新对应索引和解析规则；无需修改只读游戏数据。
- 用表清单记录模块实际使用的主表与关联/依赖表，并保留代码来源。检查共享适配器、动态表名和子模块入口；静态文本扫描只能辅助盘点，不可直接把共享脚本提到的所有表认定为每个调用模块的用表。
- “使用了某张表”只表示候选模块，不能据此判定该表所有文本都在该模块展示。精确跳转必须依据实际记录键、字段、外键和模块收录规则；保留一对多归属，并按模块与稳定条目 ID 合并结果。
- 新记录通过既有关系自动收录。未知表、未知路径、缺少关联、版本不匹配与加载失败分别保留可识别结果及诊断，不用固定实体 ID 白名单或猜测路由静默排除。仅由 Json/资产索引驱动的内容要保留其覆盖边界，不宣称远端 i18n 搜索覆盖了全部站点文字。
- 接口的 `Id` 为大写且可能是有符号 Int64；必须在 JSON 数字转换前无损保留。源字段文本 ID 与命中 ID 不一致时不生成精确跳转；缓存按关键词、语言和数据源版本隔离，并沿用隐藏模块及令牌可见性规则。
