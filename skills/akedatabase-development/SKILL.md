# AKEDatabase 开发

此文件是仓库开发流程的维护源。根 `AGENTS.md` 保存始终适用的边界；Kilo 等入口只引用这里，不复制规则正文。

## 工作范围

- 先查看当前分支、已有改动、任务相关代码和 `version.json`，保留用户改动。使用用户指定分支；不要自动提交、打标签或发布。
- 用户要求先分析时只读；允许读取代码、数据、历史会话和差异。不要把只读审阅等同于运行验证。
- `public/TableCfg/**`、`public/Json/**` 只读。功能开发不能通过修改源数据补偿错误的读取逻辑。
- 未获当前任务明确授权，不修改 README、公告、更新日志或 `public/*/tip.md`。声明版本不等于授权写公告。
- 默认不运行测试、构建、lint、格式或语法检查、Node、开发服务器、浏览器或截图；不通过子代理间接执行。用户授权验证时仅执行所授权范围，交付时说明实际执行情况。

## 数据与扩展性

- 实现前确认“源表 -> 字段 -> 关联键 -> 展示/计算”。不能仅凭文件名、ID 前缀或相似文本判定字段含义。
- 实体、属性名、分类、奖励和条件优先读 TableCfg；仅在表中缺失时使用 Json、资产索引或有来源的例外映射。索引决定资产收录范围，不能因改为表驱动而移除必要索引。
- 以真实记录和关联键枚举内容。不要用当前实体 ID、面板白名单、固定数量作为全部收录范围；未知枚举显示原始值与可识别字段，并记录未适配情况。
- 固定协议枚举或表中没有的映射允许作为例外，但须记录来源、适用范围、未知值行为。没有可靠关联时不要根据排序、颜色或名称猜测业务映射。
- 保留一对多、多对多关系及配方输入/输出。去重以稳定业务 ID 和语义为依据，不按显示名称丢弃记录；独立装备等未分组记录不能消失。
- 区分合法空数据、可选表不存在、加载失败及格式错误。失败请求应可重试；基线不可用时停用相应差分，不能把所有当前项标为新增。
- 新增数据源、过滤条件或排除规则时，同步维护收录诊断及原因。收录检查由用户手动运行，不自动访问远端。

## 公共能力与界面

- 优先复用 `AKEV3.table`、`akeDataLoader`、`akeFetch`、`AKEUI`、`parseText`、`renderRawValueTip`、`AKEVoicePlayer` 和 `__akeRouter`，先查看现有调用方式。
- 相同业务转换共用实现；页面只组织展示。避免另建取数、语音播放、配方解析或富文本管线。
- 不自行新增或修改 CSS，复用已有 `ake-ui-*` 组件。维护模块挂载/销毁、事件和异步请求生命周期。
- 界面文案遵循现有 i18n 结构、占位符和键名，默认补齐简体中文与英文，其他语言不擅自推测翻译。游戏文本从文本表本地化，缺失时保留 ID 或明确缺失状态。

## 版本

- 以用户声明的基础版本为准；未重新指定时沿用当前版本的基础部分。每个产生网站行为或资源修改的用户开发轮次只递增一次 `基础版本-pre{x}`，不能因工具调用、压缩上下文或多次编辑再次递增。
- 用户明确指定正式版、修订号、候选版时按其要求。版本值不加 `v`。
- 同步 `appversion`、所有实际受影响模块的 `pluginversion`、修改/新增脚本的 `jsversion`，未受影响条目保持不变。共享脚本需追踪 HTML 和动态加载入口。
- 仅修改规则、开发文档或独立工具且不改变网站资源/行为时，不为此刷新网站版本。
- TableCfg 版本、资产索引 revision、根清单 sharedRevision 各有语义，不能为了相同而强行同步。
